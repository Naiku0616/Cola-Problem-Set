# 构造非退化整数直角三角形

## 题意

给定正整数 `x`，构造一个三边均为正整数的**非退化直角三角形**，并使得至少有一条边等于 `x`。

- 无解输出 `No`；
- 有解先输出 `Yes`，再输出任意一组满足条件的 `a, b, c`；
- 要求 `1 <= a, b, c <= 9 * 10^18`。

## 思路

将 `x` 固定为一条直角边。根据 `x` 的奇偶性使用两组经典勾股数构造即可。

### 1. `x` 为奇数

当 `x` 是奇数且 `x >= 3` 时，输出：

```text
a = x
b = (x^2 - 1) / 2
c = (x^2 + 1) / 2
```

验证：

```text
x^2 + ((x^2 - 1) / 2)^2
= (x^4 + 2x^2 + 1) / 4
= ((x^2 + 1) / 2)^2
```

因此 `(a, b, c)` 是直角三角形。

例如 `x = 3`，得到 `(3, 4, 5)`。

### 2. `x` 为偶数

令 `k = x / 2`。当 `x >= 4` 时，`k >= 2`，输出：

```text
a = x
b = k^2 - 1
c = k^2 + 1
```

验证：

```text
x^2 + (k^2 - 1)^2
= (2k)^2 + (k^2 - 1)^2
= k^4 + 2k^2 + 1
= (k^2 + 1)^2
```

例如 `x = 4`，令 `k = 2`，得到 `(4, 3, 5)`。

### 3. 无解情况

- `x = 1`：直角三角形三边都是正整数，最短边不可能为 `1`；若把 `1` 作为斜边更不可能。
- `x = 2`：若作为直角边，另一条直角边为正整数 `y`，则斜边满足 `c^2 = y^2 + 4`，即 `(c-y)(c+y)=4`，没有满足正整数边的解；作为斜边也不可能。

所以仅当 `x <= 2` 时输出 `No`，其余情况均有解。

## 正确性证明

我们证明算法输出的结果恰好符合要求。

**引理 1：** 若 `x` 是奇数且 `x >= 3`，则
`(x, (x^2-1)/2, (x^2+1)/2)` 是非退化整数直角三角形。

**证明：** `x^2-1` 是偶数，因此后两项均为整数。由上面的等式可知前两项的平方和等于第三项平方。又因为 `x >= 3`，三条边均为正整数，且两直角边均大于 `0`，故三角形非退化。证毕。

**引理 2：** 若 `x` 是偶数且 `x >= 4`，令 `k=x/2`，则
`(x, k^2-1, k^2+1)` 是非退化整数直角三角形。

**证明：** `k >= 2`，故 `k^2-1 > 0`。由上面的等式可知前两项的平方和等于第三项平方，因此其为非退化整数直角三角形。证毕。

**定理：** 算法正确。

**证明：**

- `x <= 2` 时，按前述分析不存在满足要求的三角形，算法输出 `No` 正确；
- `x >= 3` 时，若 `x` 为奇数，由引理 1 可知构造合法；若 `x` 为偶数，则 `x >= 4`，由引理 2 可知构造合法。

两种有解情况中均有一条边为 `x`，故算法输出一定满足题意。证毕。

## 复杂度分析

每组数据只进行常数次运算：

- 时间复杂度：`O(1)`；
- 空间复杂度：`O(1)`。

## 易错点

1. **不要把 `x=3` 判成无解。** `3,4,5` 已经是合法答案，因此无解边界只有 `1` 和 `2`。
2. **偶数构造中的 `k` 是 `x/2`。** 公式应为 `(x, k^2-1, k^2+1)`，不是直接使用 `x^2-1`。
3. **必须使用 `long long` / `int64_t`。** `x^2` 最大约为 `10^18`；`int` 会溢出。`long long` 足够覆盖本题范围。
4. **先判断无解再构造。** 若 `x=2`，偶数公式会得到边长 `0`，这不是非退化三角形。
5. **输出顺序无关。** 题目只要求输出三条边；代码中按“直角边、直角边、斜边”输出更直观。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int64 x;
        cin >> x;

        if (x <= 2) {
            cout << "No\n";
            continue;
        }

        cout << "Yes\n";
        if (x & 1) {
            cout << x << ' '
                 << (x * x - 1) / 2 << ' '
                 << (x * x + 1) / 2 << '\n';
        } else {
            int64 k = x / 2;
            cout << x << ' '
                 << k * k - 1 << ' '
                 << k * k + 1 << '\n';
        }
    }

    return 0;
}
```
