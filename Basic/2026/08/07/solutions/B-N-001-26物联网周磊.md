## 题目
给定一个长为 𝑛的字符串 s，每次操作可以删除字符串中的任意一个子串 "niu" 或 "mo"（删除后剩余部分会拼接在一起）。

你可以进行任意次操作。请你判断是否可以通过若干次操作将整个字符串删光。


## 思路
开局SCANF拿信息，再根据n大小设置一个数组存放第二波输入的字符串。

之后检索数组，发现哪一位是n就进入后续判断有没有跟着iu，如果是就用'\0'替代niu，之后如法炮制代替检索出的mo。

我不把他拼在一起，所以我选择将被删掉的字符用'\0'占位，随后再检索数组阶段用函数skip_0 (int init,unsigned char arr[]);跳过占位符

每次检索到'\0'就自动跳转到数组的下一个索引(跑路了兄弟)

反复多次到判断

一直判断到不能继续删除，即FLAG=0的时候跳出循环

我利用这个函数check_arr(int l,unsigned char arr[]);判断数组状态，如果数组操作后全都是占位符就返回0，否则返回1，最后进入YESorNO判断

/*
题
给定一个长为 𝑛的字符串 s，
每次操作可以删除字符串中的任意一个子串 "niu" 或 "mo"
（删除后剩余部分会拼接在一起）。你可以进行任意次操作。
请你判断是否可以通过若干次操作将整个字符串删光。

子串：从原字符串中，连续的选择一段字符（可以全选、可以不选）得到的新字符串。

如果可以删光，输出一行 Yes；否则输出一行 No。
*/


/*
首先根据N设置一个数组存放字符串。
之后按n开头检索数组，判断n开头就进入后续判断iu，如果全部OK就删除，之后如法炮制删除mo。然后到了合并数组阶段
不合并数组，检索niu/mo之后对相应位置赋'\0'，
之后每次检索到'\0'就自动跳转到数组的下一个索引(跑路了兄弟)
反复多次到判断不能继续删除的时候跳出循环
最后进入YESorNO判断
*/

#include <stdio.h>
unsigned int n,i,j,k,temp1,temp2;//ijk给for,temp用来记索引
int flag=1;//检索删除次数标志位


//数组检查函数写外面更好看...?
int check_arr(int l,unsigned char arr[])//l为数组长度，arr为被检阅数组,返回
{
for(int i=0;i<l;i++)//检阅数组里面是不是空的
    {
        if (arr[i]!='\0')
        return 1; //牛魔没减完
    }
    return 0;//牛魔减完了
/*

    if (k==0)printf("YES");

}

int skip_0 (int init,unsigned char arr[])//当前数组的索引位置，当前数组（是不是反过来更合理?)
{
    int count=1;//init从下一位开始，判断是否为0并跳过
    while (init+count<n && arr[init+count]=='\0')//数组的最初位+count总数
    {
        count++;
    }
return count;//单纯跳过0，总共跳过了count位
}




//主函数

int main()
{
    scanf ("%d",&n);
unsigned char s[n+2];//多给几位防止扫爆了
for(i=0;i<n+2;i++){s[i]='\0';}
scanf("%s",s);
    while (flag!=0)//flag初始值为1
    {
        flag=0;//flag为本次循环是否删除过字串标志位，进循环置0
        for(i=0;i<n;i++)//逐位扫描数组内n和m，如果是n或者m开头进判断
        {
            if (s[i]=='n')
            {
                temp1=i;//存下n开头的索引
                k=skip_0(i,s)+i;//skip_0求出跳过的'0'既k=位移量加上初始量i
                if(s[k]=='i')//看看下一位是不是i
                {
                    temp2=k;//存i索引
                    k=skip_0(k,s)+k;
                    if (s[k]=='u')
                    {
                        s[k]='\0';
                        s[temp2]='\0';
                        s[temp1]='\0';//把哥仨的索引全部清零
                        flag++;//标志位
                    }
                }
            }
            if(s[i]=='m')//这里同理
            {
                temp1=i;
                k=skip_0(i,s)+i;
                if(s[k]=='o')
                {
                    s[k]='\0';
                    s[temp1]='\0';
                    flag++;
                }
            }
        }        
    }
    k=check_arr(n,s);//判断数组是不是全都是0，是的话就yes，不是就no
    if (k==0)printf("Yes");
    else printf("No");
    return 0;
}
