### 思路（关于题目“小红的牛魔”）
我是这样想的：  
打比方-题目需要我在纸上写下字符-我写完之后-去看纸的末尾-（判断纸的末尾字符是不是‘mo’和‘niu’两种类型，如果‘是’就划掉这两个字符串（也就是纸变短了）；  
假如原字符是niumo；  
抄在纸上的是ni（末尾是ni，不满足就不删掉）；  
抄在纸上的是niu（末尾是niu，满足就删掉）；  
同上（m在纸上不满足条件，而mo则满足条件）；  
删掉niu之后之前抄的mo又挨在一起了，这种看末尾进行判断的方式很巧妙。  
因为还在学习C++，故给出C语言的代码供参考：  
```c
#include <stdio.h>
char a[200000];  //防止内存溢出
int main(void){
    int b;
    char c[200000];
    scanf("%d",&b);
    scanf("%s",c);
    
    int d=0;
    for (int e=0;e<b;e++){     //相当于从左到右抄写字符
        a[d++]=c[e];
    if(d>=2 && a[d-1]=='o' && a[d-2]=='m'){      //检查末尾有没有“mo”
        d-=2;
    }
    if(d>=3 && a[d-1]=='u' && a[d-2]=='i' && a[d-3]=='n'){    //检查末尾有没有“niu”
        d-=3;
    }
    }
    if (d==0){    //判断纸上是否为空
        printf("Yes\n");
    } else{
        printf("No\n");
    }
    return 0;
}
