其实就是排序去重然后输出，没什么难理解的地方，做法很多，下面列出两种。  

# 做法一：使用set
因为不用统计，set非常好用，要统计的话可以用map
```cpp
#include <bits/stdc++.h>

using namespace std;

int N, M;

set<int> num;

int main(){

    cin >> N;

    for (int i = 0; i < N; i++)
    {
        int temp;
        cin >> temp;
        num.insert(temp);
    }

    cout << num.size() << endl;

    for(auto &p : num) cout << p << " ";

    return 0;

}
```

# 做法二：使用vector或数组  
数据很小，只有1000，所以可以拿索引当数据，值来计数  
```cpp
#include <bits/stdc++.h>

using namespace std;

int M,N;

int main(){

    cin >> N;

    vector<int> a(1001, 0), b;

    for (int i = 0; i < N; i++)
    {
        int temp;
        cin >> temp;
        a[temp]++;
    }

    for (int i = 0; i < 1001; i++)
    {
        if(a[i] != 0){
            M++;
            b.push_back(i);
        }
    }

    cout << M << endl;

    for(int p : b) cout << p << " ";

    return 0;
}
```
