# B-N-003 题解
日期：2026.08.09

## 题目大意
- 首先题目要求我们要输入几个数组，这一步使用for循环语句直接写
- 将数组输入完毕后，紧接着就要进行判断与输出（不能后置输出，代码变量会直接因为重新输入而覆盖掉，一定要在输入第一个数组时就给出判断并输出）
- 在判断和输出之前，唯一要做的就是给数组一个顺序（没有顺序就无法按顺序重新构建一个新数组进行下一步判断（当然，直接数存在多少个0和1也行，不过我没多想））
- 在排完序之后，首先要判断排完序之后的数组的第k项是不是0，如果是零，直接选择第k项之前的数（这时的数一定全部是0），答案就一定是0
- 如果不是0，就会有两种情况，一种是中位数不是1，那就输出1，另一种就是1，直接输出0
- 但在那之前先在原数组上重新倒序取k个数出来（如果从第一项开始取，就会导致可能后面1比较多，最小值可能不是1）
- 此时倒序取出来的新数组已经存在倒序了，接下来就是判断中位数的问题（倒序数组的判断跟升序数组判断存在差异，可以再选择一次排序）
- 但在判断中位数之前还要先判断奇偶问题（奇数和偶数的判断方式不同）
- 判断完就输出，整道题解答完毕

## 代码
'''C++
#include <bits/stdc++.h>
#include <algorithm>
using namespace std;
int main(){
    int num,n,k;
    cin >> num;
    for (int t=1;t<=num;t++){
        cin >> n >> k;
        int v[n];
        for (int i=0;i<n;i++){
           cin >> v[i];
        }
        sort(v,v+n);
        if (v[k-1]==0){
            cout << 0 << endl;
        }
        else {
            int c[k];
            for (int e=1 ;e<=k;e++){
                c[e-1] =v[n-e];
            }
            if(k%2==0){
                if (c[k/2]==0){
                    cout << 1 << endl;
                }
                else {
                    cout << 0 << endl;
                }
            }
            else {
                if (c[(k-1)/2]==1){
                    cout << 0 << endl;
                }
                else {
                    cout << 1 << endl;
                }
            }
        }
    }
    return 0;
}
'''
