- 在n个物品里选取k个物品使得所选的k个物品的（最大值Max - 中位数Mid）的值最小
    - 疑问：题目给的物品的价格是n个物品的价格，但要求的都是k个物品的价格，我要怎么判断选取的k个物品中每个物品的价格呢？这我根本做不到，找不到用代码实现的办法
    - 答：根本不需要知道，这题就不是怎么做的
- 关键：v只能是0或1（我之前完全没有想不到这回事理解这道题的关键，啧，申术真是个废物）
- 因为v只能是0或1，所以Max和Mid也只能是0或1，那么Max - Mid 就只有 0-0=0，1-0=1，1-1=0，这三种情况，所以答案只可能是0或1
- 只要判断Max - Min = 0 是否成立即可，如果能答案就是0，不能就是1
- 如何实现？在每次输入价值的时候判断是否是0或1，用变量存储0和1的数量，知道了n里的0和1的总数就能判断k的情况了
1. 如果n里0的数量大于等于k的数量，就可以全选0，那么Max-Mid=0;0
2. 如果n里1的数量大于等于(k的数量-中位数的下标+1)，就能让最大值和中位数都是1，那么Max-Mid=0
    -(k的数量-中位数的下标+1)就是k的数量减去从第一个数到中位数所需的数的数量，这个就是所有比中位数大的数的数量，最后+1是加上中位数本身，结果就是从中位数位置到最后一个位置的长度
3. 如果上面两种情况都不能满足，那么Max-Mid=1必然成立，因为只剩下有1但1的数量太少，没办法占据中位数的位置，导致1-0=1


## 代码
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;

    cin >> T;

    //通过while循环来计算每一组数据
    while (T--) {
        int n, k;
        int count0 = 0, count1 = 0;

        cin >> n >> k;

        for (int i = 0; i < n; i++) {
            int v;
            cin >> v;
            
            //计算0和1的数量
            if (v == 0) count0++;
            else count1++;
        }

        //计算在在有1的情况下什么条件能达成Max-Mid=0
        int midPos = (k+1) / 2;
        int need = k - midPos + 1;

        //根据情况输出
        if (count0 >= k || count1 >= need) cout << 0 << "\n";
        else cout << 1 << "\n";
        
    }

    return 0;
}
```
