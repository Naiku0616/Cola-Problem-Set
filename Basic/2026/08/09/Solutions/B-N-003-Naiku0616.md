# 思路（关于题目“mid_max”）
对于刚接触C语言的我来说，这道题目真的不容易去做，不过来都来了，还是分享一下我的解题想法；  
首先将复杂问题简化，不妨将问题核心阐明；  
把它看作是“抓娃娃游戏”，每次必须抓k个娃娃，每个娃娃的编号只能是1或者是0；  
而问题要我们计算的是：你抓到的娃娃中最大的数字减去中位的数字，最小能为多少？  
而又因为编号只有0和1，所以这些差值只有两种可能，要么是0，要么是1，我们需要让差值为0；  
有两种情况的差值为0；

## 第一种
全部是0，中位数为0，最大值也为0，所需条件为0的数量大于等于k。  

## 第二种
有编号1，但是中间那个编号也是1，最大数字为1，中位数为1；  
需确保中位数是1，假设抓了k个娃娃，它们的中位数排在第m个位置，即公式为m=(k+1)/2。  
在抓住的娃娃中，0的数量少于m个，则在m位置上的编号为1；  
可尝试抓住m-1个0，剩下抓1，这样0的数量既少于m，又留下足够位置给1；  
所需条件是：只要0的数量>=(m-1),1的数量>=(k-(m-1)),可以确保差值为0。  

## 如果不满足上述两种条件，那么无论如何，最大数-中位数的差值只能为1。
提供C语言代码供参考：
```c
#include <stdio.h>
int main(void){
    int a;
    scanf("%d",&a);  //读取几组数据
    
    while (a--) {
        int b,c;
        scanf("%d %d",&b,&c);
        
        int x=0,y=0;
        for (int i=0;i<b;i++){    //统计0和1的数量
            int d;
            scanf("%d",&d);
            if (d==0) x++;
            else y++;
        }
        int m=(c+1)/2;    //中位数在k个物品中的排序
        int zero=0;      //标记差值0能否得到
        
        if (x>=c){       //情况1：k个0
            zero=1;
        }
        int n0=m-1;      //情况2：m-1个0；剩余为1
        int n1=c-n0;
        if (x>=n0 && y>=n1){
            zero=1;
        }
        if (zero) printf("0\n");    //得到0输出0，反之输出1
        else printf("1\n");
    }
    return 0;
}
