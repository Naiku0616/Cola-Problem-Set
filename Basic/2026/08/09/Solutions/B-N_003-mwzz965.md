分析题目发现：max要么是0，要么是1     
1.当max为0时，mid必然是0，所以答案为0      
2.当max为1时，mid可能是1或0，而最好的情况是mid为1，怎么检测呢   
    对于数组v，中位数的索引***index***是固定的，那么只需要从最后一位开始填充数据，直到index处被填充上数据，此数据即为中位数     

```cpp
#include <bits/stdc++.h>
using namespace std;

int T, n, k;

int main(){

    cin >> T;

    for (int i = 0; i < T; i++)
    {
        cin >> n >> k;

        int max, mid = 0, count0 = 0, count1 = 0;

        for (int i = 0; i < n; i++)
        {
            int temp;
            cin >> temp;
            temp == 1 ? count1++ : count0++;
            //计数
        }

        max = count0 >= k ? 0 : 1;
        //算max的值
        
        if(max == 1){
            int v[k+1];
            //fill也要时间，前面用不到所以在这里写
	        fill(v, v+k+1, -1);
	        //将数组v初始化为-1，区分是否填充数据
            int index = (k+1)/2;
            //中位数的索引
            for (int i = k; i > 0; i--)
            {
                if(count1 != 0){v[i] = 1; count1--;}
                else v[i] = 0;
				//填充数据
                if(v[index] == 1) mid = 1;
                else if(v[index] == 0) mid = 0;
                //给mid赋值，其实可以提前break但是我懒得写了 
            }
        }   
        cout << max - mid << endl;
    }
    
    return 0;
}
```    
 
# 其实应该还有做法     
写知识点的时候想到了，懒得写代码了，反正是那个意思         
1.在输入的同时进行排序，因为只有0和1两个数字，所以只需要用双指针在数组的左右两端向中间迭代就能对数组v完成排序              
2.要选出k个物品找中位数，所以再用三个指针，分别代表k的左右端和中位数，此时三指针可看成一个滑块         
3.先把滑块放在v的最左端看max是否为0，即滑块的最右端指向的数据是否为0，不为0就把滑块放到v的最右端，此时滑块内部的中位数指向的就是mid
