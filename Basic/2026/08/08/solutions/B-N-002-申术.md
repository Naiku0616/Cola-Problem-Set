# DS
我犯了一个根本性的错误：我以为只要“所有最大值连成一块，所有最小值连成一块”，就能达到最小陡峭值。 这个理解是不完整且错误的。

正确的模式是：所有最大值和所有最小值必须分别位于数组的两端，形成“最大值块在一端，最小值块在另一端”的排列。

错误理解：[1, 2, 2, 1] （最小值块被最大值块夹在中间）

正确理解：[1, 1, 2, 2] （升序）或 [2, 2, 1, 1] （降序）

# 豆包
啊！！这里我犯了一个严重错误❗，我之前理解错题目“不同排列” 的定义。
题目原话：
两个方案被视为不同的，当且仅当存在一个位置 i 使得两个方案中 \(a_i\) 不同。
👉意思：只看数值序列，不看原始元素下标。
比如数组 [1,2,2]：
升序：1,2,2，交换两个 2，得到的序列还是 1,2,2，算作同一种方案！
不是统计原始元素的全排列，是统计数值序列有多少种不同的序列！

我之前错误算多重集合排列数，那是把 “元素个体” 当成不同，但是本题只看位置上的数值。

int main() {

    vector<int> a(n);
    for (int i = 0;i < n; i++) {
        cin >> a[i];
    }

    sort(a.begin(), a.end());//升序排序,防止首位相同以及计算陡峭值最小值（最大值减最小值）

    //情况1：输入的所有数都一样
    if (a[0] == a[n-1]) {
        cout << 1 << " " << 0;
    }
    //情况2：其他情况

        cout << 2 << " " << a[n-1] - a[0];
    }

    return 0;

}
