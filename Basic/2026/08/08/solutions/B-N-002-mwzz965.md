思路：
    此题有两种情况
    1.数据一样，此时只有一种排列，陡峭值为0
    2.数据不一样，则只有正序和逆序两种情况,陡峭值为极差

```cpp
#include <bits/stdc++.h>
using namespace std;

int n,ans;
vector<int> a;

int main(){

    cin >> n;
    a.reserve(n);

    for (int i = 0; i < n; i++)
    {
        int t;
        cin >> t;
        a.push_back(t);
    }
    
    sort(a.begin(), a.end());
    
    ans = a.back() - a.front();

    cout << ((ans == 0) ? 1 : 2);
    cout << " " << ans;

    return 0;
}
```

太简单啦我就不注释啦
**知识点**
**1.**
```cpp
vector<int> a;
```
不传参构造vector时，vector内数据为**空**，不能使用索引a[i]访问
正确用法是**使用push_back()**动态添加数据

**2.**  
对于sort函数，当对象为容器时使用迭代器，当对象为数组时使用地址
```cpp
sort(a,begin(), a.end());
sort(a, a+num);
```

**3.**
这两个等价，begin和end返回迭代器，需要解引用
```cpp
    ans = a.back() - a.front();
    ans = *(a.end() - 1) - *a.begin();
```
