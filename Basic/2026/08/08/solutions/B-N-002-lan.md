## 代码

```c
/*
小红定义一个数组的陡峭值为：每两个相邻的元素，差值的绝对值之和。
例如，数组 { 2 , 3 , 1 } {2,3,1} 的陡峭值是 ∣ 2 − 3 ∣ + ∣ 3 − 1 ∣ = 3 ∣2−3∣+∣3−1∣=3。 
现在小红拿到了一个由 𝑛 n 个整数组成的数组 { 𝑎 1 , 𝑎 2 , … , 𝑎 𝑛 } {a 1 ​ ,a 2 ​ ,…,a n ​ }，
她希望你将该数组重新排列，使得数组的陡峭值尽可能小。
请你输出小红有多少种不同的排列方案使得数组的陡峭值最小，并输出这个最小值。
两个方案被视为不同的，当且仅当存在一个位置 𝑖 i 使得两个方案中 𝑎 𝑖 a i ​ 不同。
*/

/*
注意到，最小陡峭值等于极差，数组想要陡峭值最小必须单调递增/减，故总共2种情况，但只有单一元素的数组陡峭值为0，且只有一种排列方式
将数组排序的方式考虑到刷到的第一个视频教的是选择排序，因此这里选择选择排序

*/




#include <stdio.h>

int main()
{
    int n,p;//存放数组最小值索引
    int i,j,temp;

    scanf ("%d",&n);//数组长度
    int s[n];
    for(i=0;i<n;i++)//数组初始化
    {
        scanf ("%d",&temp);
        s[i]=temp;
    }
    //先不检查是不是单一元素数组，后面检查也行吧
    for(i=0;i<n-1;i++)//选择排序外循环，只需扫描n-1次（最后一次的扫描只有一个数）
    {
        p=i;//为内循环做P的初始化，P为当前未排序部分第一位
        {
            for (j=i+1;j<n; j++)
            {
                if (s[j]<s[p])//如果比当前索引比P小就记录
                {
                    p=j;
                }
                
            }
            if (i!=p)
            {
            temp=s[i];
            s[i]=s[p];
            s[p]=temp;
            }
        }

    }
    if (s[n-1]==s[0])//判断是否为单一元素数组
    {
        printf("1 0");
    }
    else
    {
        printf("2 %d",s[n-1]-s[0]);
    }
return 0;
}
```
