# 思路（关于题目“小红的地势值（二）”）
在思考这道题目时，确实有过较长一段时间的不知所措；  
但是在算法设计中最忌讳的就是把简单问题复杂化； 
不妨将问题简化为“小朋友排队问题”；  
题目中提出“陡峭值（跌宕起伏度）”其实就是每两个相邻的小朋友身高差值相加；  
剖析问题实质-就是找到队伍中最高的和最矮的（数学中好像称为“极差”，即最大数-最小数）；  
再者就是确定有几种排法可行；  
1、从小到大；  
2、从大到小；  
3、（特殊情况千万不要忽略）（。  。）如果所有人都一样高的情况，最小落差肯定是0；  
给出C语言代码供参考：  
```c
#include <stdio.h>
int main(void){
    int a;
    scanf("%d",&a);  //输入人数
    
    int b=0,c=10000;   //记录最高、最矮之身高
    for (int i=0;i<a;i++){
        int d;
        scanf("%d",&d);
        if (d>b) b=d;    //动态更新最高与最矮
        if (d<c) c=d;
    }
    int e=b-c; //公式
    int x;
    
    if (b==c){
        x=1;   //极端情况：所有人身高一样高
    }
    else{
        x=2;
    }
    printf("%d %d\n",x,e);
    return 0;
}
```
