# B-C-004-题解
日期：2026.08.11
## 题目大意
- 首先题目要求去输入几个示例，跟之前的一样做个大的for循环
- 还要在包含整数内输出数值，这一步直接用数组囊括
- 要判断是否会触发护盾，只需要判断是不是所有的数都可以交替进行就可以了（要排除掉最后两个贴在一起的情况）
    1.如果所有的数都可以交替，就一定会满足这一组数的众数数量一定会小于总数除以2再加1
    2.如果存在仅有最后两个数贴在一起的情况就满足众数数量小于等于总数/2+1（也可以是众数数量等于其他量+2）
    3.如果能满足上述两种情况，就所有数的和一定是最大生命值
    4.如果不满足，则护盾触发，一定存在无效输出（基于最大输出而言）
    5.护盾一触发，就需要找出众数里无法输出的数，再减去他们就是最大生命值
    6.已知最多的有效输出要满足众数数量小于等于总数/2+1，那在这个有效输出范围里最大的众数数量就是有效输出里的众数数量，在这个前提下，众数原本的总数减去有效输出里的总数，就是要减去的众数数量，然后再由总数减去就得到最终的最大生命值

##代码
```C++
#include <bits/stdc++.h>
using namespace std;
int main(){
    int t;
    cin >> t;
    while(t--){
        int n;
        int b=0;
        cin >> n;
        vector<int> v(1001, 0);
        long long sum = 0;
        for (int i = 0; i < n; i++) {
            int a;
            cin >> a;
            v[a]++;
            sum += a;
        }
        int mx = *max_element(v.begin(), v.end());          //查询最大值出现次数
        int mode =0;
        for (int i=1; i<=1000; i++){                    //用遍历取出最大值
            if (v[i] == mx){
                mode = i;
                break;
            }
        }
        int f_mx = n-mx;          //计算最大值出现次数的补集,即其他量
        if (2 * mx <= n + 2) {                  //判断最大值出现次数是否小于等于 n/2+1，如果是小于则说明可以满足交叉输出，最大就是总和
            cout << sum << endl;
        }
        else  {                                  //如果没有就将总和减去无法造成伤害的数就是最大伤害值
            while(b-2<= f_mx && b<=mx){
                b++;
            }
            sum =sum-(mx-b+1)*mode;
            cout << sum << endl;
        }
    }
    return 0;
}
```
