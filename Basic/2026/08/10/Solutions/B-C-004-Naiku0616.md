# 思路（关于题目“Boss Fight”）
先说结论，题目对我来说很不好理解，于是我选择使用DeepSeek-V4大模型辅助理解，并非独立完成。  
由于是第一次实操C++代码，码力青涩。  
简单说一下题目问的是什么；  
我有n张牌-连续打出两张伤害相同的牌，Boss会开护盾-护盾开启后，后续打出的所有牌伤害都为0（触发护盾的牌伤害有效）；  
而我们的目标就是把伤害打到最高，基本上有两种情况：  
## 第一种情况
所有牌都能打出伤害，隔开打（例如：10 5 10 5 ），这样不会连续打出两张伤害相同的牌，护盾永远不会被开，就可以一直灌伤。  
所需条件就是设出现次数最多的牌有m张，其他牌有n张，满足m<=n+1，就可以完美隔开，答案就是所有牌的伤害总和。  
## 第二种情况
某些手牌太多了（比如4张10，1张5），无法做到都隔开，这个时候我们该怎么做？  
用那一张5隔开两个10；  
剩下两张10则捆绑放在最后，第一张10正常打出，第二张10触发护盾，但牌已打完，后续无影响。  
## 根据两种情况的结论，给出最后的C++代码提供参考：  
```cpp
#include <iostream>
#include <vector>       
#include <algorithm>     //方便排序
using namespace std;

void solve() {    //封装函数，只为测试多组数据
    int n;
    cin >> n;         //拿了多少牌
    vector<int> a(n);    //准备容器存放伤害
    long long sum = 0;   //记录总伤
    
    for (int i = 0; i < n; i++) {
        cin >> a[i];      //存放伤害
        sum += a[i];      //计入总伤
    }
    sort(a.begin(), a.end());       //排序，便于统计牌数
    
    int max1 = 1;     //目前出现次数最多的牌
    int max2 = a[0];    //出现次数最多的牌[数值]
    int cur = 1;    //当前正在查的牌
    
    for (int i = 1; i < n; i++) {     //循环检查一下，从第二张牌开始
        if (a[i] == a[i-1]) {
            cur++;        //数字相同，数量+1
        } else {
            if (cur > max1) {      //动态更新
                max1 = cur;
                max2 = a[i-1];
            }
            cur = 1;
        }
    }
    if (cur > max1) {        //检查最后一批牌
        max1 = cur;
        max2 = a[n-1];
    }
    
    int others = n - max1;      //总牌数-最多的牌的数量=隔开相同数字的其他牌
    
    if (max1 <= others + 1) {      //满足条件m<=n+1
        cout << sum << "\n";
    } 
    else {
        //第二种情况的计算方式为总伤害=（其他牌数量+2）*最多的那个数字+（所有牌总数-最多牌原本的总和）
        long long ans = (long long)(others + 2) * max2 + (sum - (long long)max1 * max2);
        cout << ans << "\n";
    }
}
int main() {
    int t;
    cin >> t;
    while (t--) {      //执行函数solve()测试多组数据
        solve();
    }
    return 0;
}
```
