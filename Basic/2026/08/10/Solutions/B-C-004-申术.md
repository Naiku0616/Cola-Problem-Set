# B-C-004 题解

## 题目大意
（居然要看英文了吗，算了，还是先看翻译的吧）

对于给定的n张卡牌，每张卡牌有各自的伤害，可以对他们进行排序任意，然年后依次打出

如果有两张连续的牌伤害一样，那么后面卡牌的伤害都为0

~~怎么排序才能打出最大的伤害~~

怎么让打出的伤害总和尽可能地大？

有t轮测试用例

### 思路
要对每张牌进行排序，只要不让伤害一样的牌连在一起就可以了


1. 思路一（错误思路，别看）
    - 先对所有牌从小到大排序
    - 再从小到大拿牌，如果当前拿的牌的伤害和上一张的伤害一样就跳过拿下一张
    - 拿完一轮之后再对没有拿的牌进行新一轮的拿取(进入新的轮次要清空记录)，以此类推，直到只拿完
    - 如果最后剩下的牌数值都一样就对剩下的牌进行交错插入已经排好序的卡组，~~因为剩下的牌数值一定是最大的~~（剩下的牌一定是最多的，是众数）
    - 然后再把拿到的牌的伤害按顺序加起来，前后相加的数一样就结束计算，达成总伤害最大，输出答案
    - 最后清空数组到下一组

    #### 代码
    ```C++
    #include <bits/stdc++.h>
    using namespace std;

    //交错插入的函数（没学过，不会写，要靠AI）
    void cardInsert(vector<int>& a, vector<int>& b) { //&是引用数据，而不是直接复制，是对导入的数据直接修改，又学到了
        int v = a[0];
        int index = a.size() -1;//开头那张可以留在原地所以-1

        for (int pos = b.size(); pos >= 0 && index >= 0; pos--) {
            b.insert(b.begin() + pos, v);
            index--;
        }

        a.clear();//插入完毕，清空数组
    }



    int main() {
        int t, n, ans = 0;
        vector<int> a, b ;
        cin >> t;

        for (int j = 0; j < t; j ++) {
            cin >> n;//输入牌的总数
            int temp;

            //输入每张牌的伤害
            for (int i = 0; i < n; i++) {
                cin >> temp;
                a.push_back(temp);
            }
            
            //对卡牌从小到大排序
            sort(a.begin(), a.end());

            int count = 0;//靠计数器往后推数组的下标，实现跳过
            temp = 0;//伤害都是正数，所以a的元素里不可能是0

            for (int i = 0; ; i++) {

                //判断是否拿完了所有的数值不同的牌，拿完了就开始新的一轮,重置count和temp
                if (count >= a.size()) {
                    temp = 0;
                    count = 0;

                    //检测剩下的牌是不是都相同
                    bool same = (a.front() == a.back());
                    if (same) {
                    cardInsert(a, b);
                    break;
                    }

                    continue;
                }

                if (a.empty()) break;//a空了就证明没有相同的牌，直接退出

                //判断伤害是否一样，一样就跳过拿下一张
                if (temp == a[count]) {
                    count++;
                    continue;
                }

                //拿牌
                temp = a[count];
                b.push_back(temp);

                
                a.erase(a.begin() + count);

                
            }

            //把拿到的牌的伤害按顺序加起来，前后相加的数一样就结束计算
            temp = 0;
            for (int i = 0; i < n; i++) {
                if (temp == b[i]) break;
                temp = b[i];
                ans += b[i];
            }

            cout << ans << endl;

            //清空数据
            ans = 0;
            a.clear();
            b.clear();
            }

        return 0;
    }
    ```

2. 思路二（AI提供的数学解法）
   - 这我可根本想不到，好像是高中学的隔板法？不对，是插空法
   - 核心思想：只关注出现次数最多的牌，他决定了盾牌什么时候触发
   - 推导如下：
        - ans:答案 
        - n:卡牌总数
        - m:众数牌的张数（出现次数最多的牌）
        - v:众数牌的伤害
        - sum:所有卡牌伤害的总和
        - rest = n-m:其他牌的数量
        - useless:无效牌的数量
        - 能否重排数组，使得相邻元素不重复？(插空法)
        - 如果m <= rest+1，众数牌都能插空，就没有相邻相同的情况，牌能全部打出去，ans = sum
        - 如果m > rest+1，众数牌不能全部插空，有众数牌会多出来，那么怎么放这些没法插空的众数牌才能打出最大的伤害？
        - 只能在末尾再多加一张众数牌，剩下的众数牌只能作废，也就是useless
        - 统计一下，所有能打出伤害的牌：rest + rest + 2
        - 解释：rest为非众数牌 ,能产生rest+1个空隙让众数牌插空，最后再+1张众数牌，剩下的牌作废
        - 最后有效伤害总和 = 所有卡牌伤害的总和 - 所有众数牌的伤害 + 所有能插空的众数牌的伤害 + 最后能打出的众数牌的伤害
        - 换算在这里写比较麻烦，还是自己写在草稿纸上吧。
        - useless = 2*m -n -2
        - ans = sum - useless * v
    - 好了可以开始写代码了
    #### 代码
    ```C++
    #include <bits/stdc++.h>
    using namespace std;

    int main() {
        int t;
        cin >> t;

        while (t--) {
            int n;
            cin >> n;

            
            long long sum;
            unordered_map<int , int> card;//这玩意叫哈希表啊，查了查，跟Python里的字典很像,键值对？
            
            for (int i = 0; i < n; i++) {
                int x;
                cin >> x;
                card[x]++;//存储牌地伤害和对应得张数 x，y --> 伤害，牌数
                sum += x;//累加，计算所有牌得伤害总和
            }

            int m = 0, v = 0;

            //筛选众数，遍历一次哈希表，找到出现最多得牌，记录牌数和伤害
            for (auto &p : card) {
                if (p.second > m) {
                    m = p.second;
                    v = p.first;
                }
            }
            //根据公式计算出答案
            long long useless = 2LL * m - n - 2;
            if (useless < 0) useless = 0;//m <= rest+1的情况

            long long ans;
            ans = sum - useless * v;

            cout << ans << "\n";
        }
        return 0;
    }
    ```
