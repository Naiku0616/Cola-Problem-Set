# B-C-005 题解
日期：2026.08.12

## 题目大意
- 题目要求我们输入几组测试用例就跟之前一样
- 这次题目要我们对是否可以进行邻位互换进行判断
- 首先是明确题目是要我们进行奇数位与偶数位进行互换（例如第一与第二，第三与第四，不可以第二和第三（这样第一就没有可以互换的位置了））
- 题目中描述的完美整数其实是介乎于奇数数组的最小和偶数数组的最大之间，且一定为整数，与原数组中任何数都不同
- 那就要判断奇数数组的最小值和偶数数组的最大值，直接使用sort函数进行升序排列，其首和尾就是最小和最大值
- 然后就是判断完美整数是否存在的问题了
## 代码
```C++
#include <bits/stdc++.h>
#include <algorithm>
using namespace std;
int main(){
    int num;
    cin >> num;
    while(num--){
        int n;
        cin >>n;
        int v[n-1];
        for(int i=0;i<n;i++){
           cin >> v[i];
        }
        if (n %2 ==1 ){
            cout << "NO" << endl;
            continue;
        }
        int v1[n/2],v2[n/2];            //v1存放奇数位，v2存放偶数位
        for (int i=0;i<n;i++){
            if (i%2==0){
                v1[i/2] = v[i];
            }
            // 将v数组中的奇数项赋值给一个新的数组方便接下来判断
            else {
                v2[i/2] = v[i];
            }
            // 将v数组中的偶数项赋值给一个新的数组方便接下来判断
        }
        sort(v1,v1+n/2);
        sort(v2,v2+n/2);
        int k=v2[n/2-1];
        // 为了方便计算加快和精准判断，直接给k赋值一个偶数项中最大的值，确保偶数项都可以顺利互换
        while (k<v1[0]-1){
            // 用奇数项的最小值去验证奇数项是否都能顺利互换
            k++;
        }
        // 顺手求出完美整数的最大值是什么
        if (k==v2[n/2-1] || k==v1[0]){
            // 为了防止出现while循环过后出现k等于数组中的数
            cout << "NO" << endl;
        }
        else {
            cout << "YES" << endl;
        }
    }
    return 0;
}
```
