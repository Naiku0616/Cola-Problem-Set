# **这题比上题简单！！！！**   

分析题目可知：  
    1.奇数项要向右，偶数项要向左   
    2.奇数列不可能有完美的k  
    3.奇数项要大于k，偶数项要小于k  

核心解题思想：   
找奇数项最小，偶数项最大。则有   最小 > k > 最大   

```cpp
#include <bits/stdc++.h>

using namespace std;

const long long B = 1e9+10;

int t;

int main(){

    cin >> t;

    for (int i = 0; i < t; i++)
    {
        int n;
        cin >> n;
  
        if(n%2 != 0){
        //这是一个特判，奇数直接输出NO
            int del;
            //多余数据直接输入给del销毁
            for (int i = 0; i < n; i++) cin >> del;
            cout << "NO" << endl;

            continue;
        }
        

        long long big = B, sma = 0;
        //big > k > sma
        //为什么是long long呢，我需要一个大于1e9的数，显然超过了int，故使用ll

        for (int i = 1; i < n+1; i++)
        {
            long long temp;
            cin >> temp;

            if(i%2 != 0){
            //奇偶判断
                big = min(big, temp);
                //大的里面找最小
            }
            else sma = max(sma, temp);
            //小的里面找最大
        }
        
        // cout << big << " " << sma << endl;

        if(sma+1 < big) cout << "YES" << endl;
        //比如一个1-3的数，1+1=2 < 3，而4-3的数4+1 !< 3
        else cout << "NO" << endl;

    }
    
    return 0;
}
```
