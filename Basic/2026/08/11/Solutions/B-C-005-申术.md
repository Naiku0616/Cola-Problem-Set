# B-C-005 题解

## 题目大意
有n+2个位置，从0到n+1。

初始时, 1 到 n 上各有一个元素，第 i 个位置的元素重量为 wᵢ。位置 0 和位置 n+1 是空的。

输入一个整数K，然后所有元素都会移动一次：

- 如果 wᵢ < k，位置 i 上的元素移动到 i-1；

- 如果 wᵢ > k，位置 i 上的元素移动到 i+1；

- 如果 wᵢ = k，整个移动过程立刻失败。

如果移动没有失败，并且移动完成后，位置 1 到 n 的每一个位置都恰好有一个元素，则称整数 k 是“完美的”。

请你判断：是否存在一个完美的整数 k。

## 思路

### 思考过程
所以说刚开始时是这样：口 w1 w2 w3 …… wn 口

然后输入k，每个元素都会移动，根据k和w大小比较的结果来决定移动方向，向前或向后1位置还是在原地

要求完美k不能移动失败，所以有w=k就不是完美k

还要位置 1 到 n 的每一个位置都恰好有一个元素，即0和n+1上不能有元素，因为所有的元素都要移动，所以必定有w1 > k和wn < k，根据这个结果又能推断其它的元素，所以就是位置互换

好了，思路似乎出来了，位置互换，口（w1 <-> w2） …… （wn-1 <-> wn）口

不对，才发现没让输入k，问存不存在完美k，所以只要能位置互换就存在，关键还是能不能位置互换

什么情况没有完美k呢
- 有w=k
- n为奇数（没办法每个都互换）
- 不满足（k < w1 && k > w2） …… （k < wn-1 && k > wn）

### 思路一
怎么实现位置互换呢？
- 先记录每个w的位置和大小（用哈希表？）
- 如果w=k或n为奇数完美k直接不存在
- 然后看有没有一个整数k满足（k < w1 && k > w2） …… （k < wn-1 && k > wn）
- 查询对比之后就能确认存不存在了完美k了
  
这次我的思路应该是对的了吧？别到时候又写完代码发现自己思路错了

不对，写着写着发现这个整数k并不确定,不能用哈希表搞，靠，卡住了，能怎么办？

区间取交,没学过，还是要跟AI学一下这个再来做题，看来以后可以看一下学长给的提示然后先把提示里的知识点学了再来做题

我知道了！（k < w1 && k > w2） …… （k < wn-1 && k > wn） ==> （w2 < k < w1） …… （wn < k < wn-1）

（ w2 < k < w1） …… （wn < k < wn-）这是每个不同区间，k要在每个区间的交集里

所以（b < k < a）,找到所有a里的最大值和b里的最小值就可以确定k存不存在了！

### 代码
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n;
        cin >> n;
        
        vector<double> w1, w2;
        double temp;
        for (int i = 0; i < n; i++) {
            cin >> temp;
            if (i % 2 == 0) w1.push_back(temp);
            else w2.push_back(temp);
        }

        if (n % 2 != 0) {
        cout << "NO\n";
        continue;
        }

        double a, b;
        sort(w1.begin(), w1.end());
        sort(w2.begin(), w2.end());
        a = w1.front();//取最小值
        b = w2.back();//取最大值

        if (b >= a) {
            cout << "NO\n";
            continue;
        }
        else {
           if (b + 1 < a) cout << "YES\n";
           else cout << "NO\n";
        }
    }

    return 0;
}
```
