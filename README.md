# 可乐题单

欢迎来到可乐题单。这里每天更新三道不同难度的题目，欢迎大家阅读、思考，并提交自己的题解。

## 每日题目

每日一题分为三个档次：

- **基础题**：适合入门练习，帮助巩固基本知识与思路。
- **进阶(Cola)题**：需要更完整的分析和一定的解题技巧。
- **板子题**：用于学习和整理常用算法模板、代码模板与经典写法。



## 提交题解

所有题解请上传到统一的 `solutions/` 文件夹中，并按对应的日期与题目档次分类存放。



题解文件命名格式：

```text
题号-用户名.md
```

## 提交 Pull Request 规范

提交题解后，请通过 Pull Request 提交。

Pull Request 标题请按以下格式命名：

```text
年月日-题号-用户名

例如:
2026-08-07-X-Y-001-alice
2026-08-07-X-Y-002-hamstercube
X:题单分类
Y:来源平台
```

请在题解中写清楚你的思路、算法或步骤；如果有代码，也可以一并附上。欢迎用不同的解法互相交流。
