# Cola Problem Set

一个面向算法竞赛学习的每日题单仓库。

每天发布基础题与进阶题，欢迎阅读题目、独立思考，并通过 Pull Request 分享自己的题解。

## 题单内容

每日题目分为两个档次：

| 分类 | 说明 |
| --- | --- |
| `Basic` | 面向入门和基础巩固，侧重常见知识点与基本算法。 |
| `Cola` | 面向进阶练习，需要更完整的建模、分析和算法技巧。 |

题目文件会给出题目链接与简短提示。提示用于指引思路，不代替完整题解。

## 目录结构

每道每日题目按题单分类和日期归档：

```text
.
├── Basic/
│   └── YYYY/MM/DD/
│       ├── Problems/
│       │   └── B-平台-编号.md
│       └── Solutions/
│           └── B-平台-编号-用户名.md
├── Cola/
│   └── YYYY/MM/DD/
│       ├── Problems/
│       │   └── C-平台-编号.md
│       └── Solutions/
│           └── C-平台-编号-用户名.md
└── README.md
```

- `YYYY/MM/DD` 为题目发布日期，例如 `2026/08/13`。
- `Problems/` 存放当天发布的题目。
- `Solutions/` 存放参与者提交的题解。
- 新增内容请统一使用 `Problems`、`Solutions` 的大小写，避免跨平台路径问题。

## 题目文件格式

题目以 Markdown 表格记录，建议使用以下格式：

```markdown
| 难度 | 题目 | 提示 |
| --- | --- | --- |
| 基础 | [题目名称](https://example.com/problem) | 关键词 1、关键词 2 |
```

## 提交题解

1. Fork 本仓库，并创建自己的分支。
2. 找到对应日期、分类与题号的目录。
3. 在该日期的 `Solutions/` 下新增题解文件。
4. 提交 Pull Request，等待讨论与审核。

题解文件名统一为：

```text
题号-用户名.md
```

例如：

```text
B-L-006-alice.md
C-L-006-hamstercube.md
```

题解建议至少包含：

- 问题分析与关键观察；
- 使用的算法及其正确性说明；
- 时间复杂度和空间复杂度；
- 可运行的参考代码（可选，但推荐）；
- 不同解法、易错点或扩展思考（可选）。

## Pull Request 规范

一个 Pull Request 尽量只提交一道题的一个题解，标题使用下面的格式：

```text
YYYY-MM-DD-题单分类-平台-题号-用户名
```

例如：

```text
2026-08-13-B-L-006-alice
2026-08-13-C-L-006-hamstercube
```

- `B` 表示 `Basic`，`C` 表示 `Cola`。
- 平台标识与题目文件保持一致，例如 `L` 表示洛谷。
- 提交前请确认文件路径、文件名和链接无误。
- 请勿在同一个 PR 中混入无关格式调整或其他日期的修改。

## 参与方式

欢迎通过 Issue 反馈题目链接失效、题面问题或题单建议；也欢迎提交新的题解，与大家交流不同的思路。

学习算法的重点不只是得到答案，更是理解为什么这样做有效。祝你刷题愉快。
